Surgical admin styling patch. Copy these two files to D:\amaniadmin\src\ after backing up originals. Run npm run build. No database changes. Occupied=green, vacant=orange, maintenance=red, notice=purple. IMPORTANT: notice reaching due date is NOT automatically converted to vacancy by a CSS/JS presentation patch. That requires a separate server-side, transactional move-out workflow with verified notice date and tenancy updates; changing status from notice alone could incorrectly advertise an occupied unit. Charts use existing live analytics and enriched tooltips.
